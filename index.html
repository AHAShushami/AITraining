Modul 1

Gemini sebagai 'Jurutera'

Tiada pengalaman IT? Tiada masalah. Kita akan belajar cara memberi arahan (prompt) kepada Gemini untuk membina alat berfungsi.

Drafting HTML Forms

"Write a single file HTML code for a BMI calculator for Malaysian adults."

Semakan Logik

"Check this logic for cardiovascular risk scoring based on the table provided."

> Generating code...

Skill Wajib: Kejuruteraan Prompt

Kualiti output bergantung kepada kualiti arahan. Gunakan formula "Act As".

// Formula Prompt yang Berkesan

Act as: "Seorang Pakar Perubatan Kesihatan Awam di Kedah..."

⬇ Memberi persona dan tahap autoriti.

Task: "...yang perlu menerangkan SOP Wabak Denggi kepada MO baru..."

⬇ Memberi konteks spesifik.

Format: "...sediakan jawapan dalam bentuk senarai semak (checklist)."

⬇ Menentukan bentuk output yang dimahukan.

Constraint: "...hanya gunakan Garis Panduan KKM terkini 2023."

⬇ Menetapkan had sempadan data.

Lalukan tetikus (hover) pada baris kod di atas untuk penjelasan.

Modul 2

Menghapuskan Halusinasi

Kesihatan Awam tidak boleh bertoleransi dengan "tekaan" AI. NotebookLM menggunakan RAG (Retrieval-Augmented Generation) untuk membumikan jawapan hanya pada dokumen yang kita muat naik.

Peraturan Emas:

"Jika ia tiada dalam PDF yang dimuat naik, NotebookLM tidak akan mereka ciptanya."
